# Public result provenance

This public research repository contains **six CSV summaries manually transcribed from Tables 3–6 of the accepted manuscript** under `results/paper_tables/`.

These files are **not raw experiment runs**, are **not regenerated** by the included scripts, and must not be described as independently reproduced evidence. Mean values, SDs and effect estimates may be rounded in the accepted paper.

| CSV | Manuscript source |
|---|---|
| `table3_binary_robustness.csv` | Table 3, best ten-seed configurations |
| `table4_nested_qubo.csv` | Table 4, fixed vs nested QUBO |
| `table5_stress_and_eight_class.csv` | Table 5, stress and eight-class |
| `table6a_cross_corpus.csv` | Table 6(a), cross-corpus analysis |
| `table6b_hardware_noise.csv` | Table 6(b), simulated-noise comparison |
| `table6b_circuit_variants.csv` | Table 6(b), circuit variants |

**Intentionally omitted:** raw experiment logs, internal JSON configurations, original project archive paths, unpublished manuscript figures, acceptance correspondence, paper PDF, licensed media and processed feature arrays.

After publication, validate these summaries against the final publisher version and replace provisional bibliographic metadata with its official DOI.
