# Release checklist before making the repo public

- [ ] Confirm each coauthor agrees on code/result release and selected license.
- [ ] Check Springer's LNCS manuscript self-archiving policy after copyright forms are signed. Do not upload camera-ready PDFs by default.
- [ ] Keep acceptance emails, screenshots, personal identifiers, review correspondence and classroom materials out of the public repo.
- [ ] Check RAVDESS/CMU-MOSEI redistribution licenses before adding data or embeddings.
- [ ] Locate and review original `.py`/`.ipynb` experimental source code; scan for tokens, local drive paths and accidental credentials.
- [ ] Obtain final 10-seed and five-seed experiment logs where possible; confirm table/figure consistency with the final accepted camera-ready version.
- [ ] After the conference and publisher release, update title/author order (if needed), publication venue, official DOI, `CITATION.bib`, `CITATION.cff`, paper link and badge status.
- [ ] Recheck requirements/environment lockfile if full training source is subsequently added.
